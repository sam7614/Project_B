# 요구분석을 위한 사전 자료와 확보·활용 계획

작성:2026-10-27 / 보고서v0.8 보완 / 실제 조사·타당화 미실시

## 가. 사전 자료의 의미와 분석 단위

본 연구에서 요구는 화면에 추가하고 싶은 기능의 목록 자체가 아니라, 사용자가 수행해야 할 학업 설계·상담 과업과 현재 지원 환경 사이의 불일치이다. 따라서 설문에 앞서 무엇을 판단해야 하는지, 어떤 규정을 적용해야 하는지, 누가 판단과 기록의 책임을 갖는지, 실제로 어떤 정보를 사용할 수 있는지를 명시한다. 사전 자료는 규범적 기준, 현행 과업과 사용 맥락, 기술적 자료 구조, 이해관계자의 경험을 구분하여 구성한다. 연구자가 예상한 불편과 실제 사용자에게 확인된 요구를 동일하게 취급하지 않는다.

선정 계획서10–11쪽은 문헌·사례·예비조사와 최종 사용자인 교수자·학습자의 요구를 설계 요소에 연결하도록 하고,14쪽은 도구 개발·기관 절차·설문과FGI·분석의 순서를 제시한다. 이번 보완에서는 해당 쪽을 다시 읽어 사전 자료의 범위를 정리했다. 문서에 과거 계획 월이 적혀 있다는 이유로 실제 승인·조사가 이루어졌다고 보지 않는다.

분석 단위는 ‘사용자 역할×의사결정 과업×필요 정보×현재 수단×제약’이다. 예를 들어 미이수 항목 확인은 교육과정 기준과 학생 이수 행을 비교하는 과업이다. 현재 프로토타입이 이 비교를 표시할 수 있다는 사실은 교수자의 실제 시간 부담이나 학생의 요구 강도를 입증하지 않는다. 전자는 기술 검증, 후자는 별도 조사 자료로 다룬다.

## 다. 수집·분석·추적 절차

기존Google Docs의FGI질문지(준비 초안)를 다시 읽었다. 공통 도입·학생/교수자별 질문·후보 기능 분류·기록/코딩 틀이 있으나 실제 면담 자료가 아니다. 이번 설문과 역할별 용어·기능 제시 순서를 맞춘 뒤 사용하며 원본은 보존한다. https://docs.google.com/document/d/12ww_k-mh6sUTailqf6ytczRJm83c7O0Vsf3nWSWPmZQ/edit

PR01·PR02·PR05·PR06·PR07은 현재 확보한 범위에서 문항의 잠정 근거를 제공한다. PR03·PR04·PR08의 현장 자료는 조사 이전에 확보하거나 미확보 사유와 가능한 해석 범위를 남긴다. 실제 상담 자료를 요청할 때에는 먼저 빈 양식과 업무 지침으로 구조를 파악하고, 식별 가능한 과거 상담 기록이나 성적 원장을 공개 저장소로 옮기지 않는다.

각 사전 자료의 등록 항목은 자료ID, 제목/기관, 적용연도·버전, 확보일, URL 또는 비공개 보관 위치, 확인한 쪽/절, 추출한 사실, 연구자의 해석, 연결 문항, 미확인 사항이다. 실제 사람의 의견에는 수집 방식과 동의 범위를 별도로 기록한다. 동일 자료라도 원문 사실과 설계 가설은 별도 칸에 작성한다.

분석 흐름은 ‘사전 자료 등록→과업/문제 진술→요구 후보→문항I/C→내용·이해도 검토→실제 조사→요구도/질적 분석→기능 결정’이다. 예비 면담에서는 먼저 기존 과업과 어려움을 묻고, 이후 기능 설명과 화면을 제시해 추가 의견을 확인한다. 화면을 먼저 보여 주어 연구자의 설계에 맞춘 답을 유도하는 위험을 줄이기 위한 본 연구의 절차적 선택이다(Karademir et al., 2024).

한 기능이 필요하다는 응답만으로 구현 우선순위를 확정하지 않는다. 역할별 중요도·현재 지원의 차이, 질적 이유, 규정·자료 가용성, 보안과 구현 의존성을 함께 검토한다. 요구 우선순위와 구현 선행 순서는 별도 열로 보관한다. 근거가 부족하면 ‘추가 확인’으로 남기고 가상 응답을 보충하지 않는다.

## 라. KCI 웹 기반 교육 시스템 개발 연구의 벤치마킹

검색일은2026-10-27이며 KCI에서 웹/대시보드/프로토타입/요구분석을 조합하고 제목·DOI로 상세 레코드를 확인했다. 관련성이 높은2024–2026년 연구를 목적 표집한 방법 벤치마킹이며, 전체 검색 건수나 체계적 고찰·질 점수를 산출한 연구가 아니다. ‘완성도’는 인용 수의 순위가 아니라 사전 자료–요구–설계–평가의 연결을 참고할 수 있는지로 판단했다. 표의 적용 방안은 본 연구자의 재설계이며 원 논문의 설문을 복제하지 않았다.

KCI5편은 공개 레코드의 서지·초록 범위에서 확인했다. 임은선 등(2025)의 학회PDF는 이번 환경에서 파일 대신스크립트 응답이 와 전문을 확보하지 못했으므로 세부 설문 원문을 읽었다고 기록하지 않는다. 국제 비교인 Karademir 등(2024)의 출판사 본문3절/4절은 사전 문제 탐색→아이디어→템플릿 검토의 구분, Mohseni와 Masiello(2026)의 본문은 면담→설계→개발/사용성→현장 적용의 연결을 확인했다. 해외 사례도 우리의 실제 조사·효과 근거가 아니다.

## 마. 문항 도출과 자료의 역할

PR01·PR02·PR05·PR06에서 이수 현황/남은 항목/근거의 R01–R03을, PR01·PR03·PR04에서 목표·변경·성찰의 R04–R06을, PR03·PR04·PR05에서 피드백·후속 관리의 R07–R08을, PR01·PR03·PR07·PR08에서 제안 근거·교수자 판단·오류·권한의 R09–R12를 잠정 구성했다. 현장 자료가 없는 문항은 계획·선행연구에 기초한 후보라는 한계를 유지한다. 전체 문항/개념/자료/과업 대응은 needs-instrument-design.md와 JSON 원문에서 확인한다.

공식 교육과정은 무엇을 확인해야 하는지의 기준이고, 합성 이수 자료는 계산·연계·오류 처리를 시험하는 입력이다. 교수자·학생의 실제 설문/면담은 필요와 현재 지원 경험을 확인하는 자료이며, 전문가는 문항의 적절성과 설계의 타당성을 검토한다. 이 네 자료를 서로 대체하지 않는다.
