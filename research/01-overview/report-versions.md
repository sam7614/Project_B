## 원고와 상세 비교

- 과거 수정 파일의 줄 단위 차이는 위 커밋 링크의 Changes에서 확인한다. 당시 Google Docs 전체 원고와 Git 장별 문서가 완전히 같은 파일이라고 가정하지 않는다.
- v0.3 원고 스냅샷은 이번 버전 관리 시작 직전 Google Docs에서 읽은 내용을 보관한 것이다. 보관 시점은17:43 이후이며11:43 당시의 문서를 완전 복원했다고 주장하지 않는다.
- v0.4부터는 완료 시점의 전체 구글독스 텍스트 스냅샷과 대상 버전·기준 버전·확보 시각·내용 해시를 `research/versions/`에 보관한다.
- Google Docs 자체의 자동 버전 기록은 별도로 유지된다. 현재 연결 도구에서 Google Docs의 ‘이름 지정된 버전’을 생성하는 작업은 수행하지 않았다.
- 웹앱의 브라우저 개인 초안과 Google Docs는 자동 양방향 동기화되지 않는다. 연구자의 직접 편집은 다음 작업 시작 시 다시 읽어 보존하고, 반영한 내용을 구분한다.
