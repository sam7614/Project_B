# 전문가 검토·형성평가·수정 결과

## 문서 상태

계획서 기반 작성 틀 · 실제 연구 수행 및 결과는 확인 후 기록

## 계획서 근거

계획서 5, 10~12, 14쪽 · 전문가 타당성 검토(델파이 등), 시나리오 보완

## 작성 지침

실제 적용한 검토 방법, 전문가 선정 기준·인원·차수·문항·판정 기준을 명시하세요. 델파이는 실제 실시했을 때만 기록하세요. 의견 → 수정 → 재검토를 연결하고 사용자 검토와 전문가 판단을 구분하세요.

## 필요한 근거

검토 도구, 익명화된 평정·의견, 지표 산출, 수정 전후 비교
