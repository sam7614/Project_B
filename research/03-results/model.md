# 설계 원리·개념 모형·알고리즘

## 문서 상태

계획서 기반 작성 틀 · 실제 연구 수행 및 결과는 확인 후 기록

## 계획서 근거

계획서 9~12, 14쪽 · 상담 이력·성찰·인간-AI 협업

## 작성 지침

각 설계 원리의 문헌/요구분석 근거와 반영 기능을 대응시키세요. 입력 데이터 → AI 제안 → 교수자 검토 → 학습자 선택·성찰 → 이력 갱신 흐름과 예외·오류 처리, 추천 근거 제공 방식을 기록하세요.

## 필요한 근거

요구-기능 대응표, 개념 모형, 알고리즘 플로차트, 결정 기록
