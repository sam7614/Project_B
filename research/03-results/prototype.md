2026년 10월 23일, 연구자가 제시한 교수자용 대시보드(https://micro-degree-student.vercel.app/)를 초기 프로토타입 후보로 사전 검토하였다. 공개 화면의 주요 상호작용과 관련 클라이언트 코드를 확인하였으며, 원본 소스 버전·개발 시점·실제 운영 범위는 추가 확인 대상으로 남겼다.

학생 이수 현황, 학생 검색·모듈 필터, 학생 상세, 성취도 시각화, 상담 브리핑과 모듈 통계 화면은 교수자의 상담 준비와 교육과정 현황 파악을 지원하는 설계 요소로 활용할 수 있다. 학생 상세에는 상담 이력·입력창과 출력용 화면 구성이 있으나, 확인한 배포본에서는 공통 예시 이력과 저장·전송이 연결되지 않은 UI가 포함되어 있었다.

학생·성적·관계 데이터에는 무작위 생성 로직이 있으며 일부 요약 지표는 고정 예시 값이다. 상담 가이드의 확인된 부분은 조건과 사전 문구에 따라 표시된다. 따라서 이를 실제 학생의 상담 결과, 검증된 통계 또는 생성형 AI의 성능 근거로 사용하지 않는다.

이 개발물은 교수자용 초기 버전으로 위치시키고, 문헌·요구분석을 통해 재검토하여 상담 이력 축적, 학습자의 모듈 조합·성찰, 시스템 제안에 대한 교수자의 판단 추적을 보완할 계획이다. 기존 화면과 후속 연구에서 추가·수정한 기능은 구분해 기록한다. 이 사전 검토만으로 최종 시스템의 타당성이나 교육적 효과가 검증되었다고 해석하지 않는다.

후속 원본 확인에서 TU-Professor-Assistant 저장소의 커밋 74d467fb393906dbdc6ee76d898fada810dbb60a에 포함된 tu-professor-assistant.zip 내부 교수자용 소스가 배포 화면과 대응함을 확인하였다. 저장소 최상위의 학생용 코드와는 구분되며, 배포 원본 커밋과 Vercel 연결 설정은 추가 확인 대상이다. 연구자는 이 교수자용 페이지를 지속적으로 개선할 의사를 밝혔으며, 코드 구조·배포 경로를 정리한 후 기능 개선과 연구 검증을 진행하는 방향을 기록하였다.

후속 개발 기반 정비에서는 교수자용 코드를 src 구조로 복원하고 기존 학생용 코드를 legacy로 보존하였다. lockfile 기반 재설치, 타입 검사와 프로덕션 빌드를 통과했고, 로컬 및 실제 운영 주소에서 주요 화면과 모바일 동선을 확인하였다. 기존 Vercel 프로젝트의 Git 연결을 TU-Professor-Assistant/main으로 수정하여 커밋 fc31789011e90756fb38292959f225f757f5dd0d가 기존 운영 주소에 자동 배포된 사실을 확인하였다. 이는 개발·배포 기반 정비에 관한 기술 결과이며 실제 상담 저장·학사 연계나 교육적 효과의 검증을 뜻하지 않는다.

2026년 10월 25일에는 실제 학생 원자료를 사용하지 않는 고정 시드의 합성 데이터 생성·검증 체계를 구성하였다. 전체20,000건을 생성하고 학년4×모듈4×상황16의256건 fixture를 앱에 연결했다. 대시보드의 학생 수·평균 이수율·조건별 상담 대상 수를 같은 데모 집합에서 계산하고 화면·출력에 합성 자료임을 표시했다. 재생성 일치와 데이터 제약, 타입·빌드 및 로컬 주요 화면 검사를 통과했다. 이 작업은 구현과 시나리오 점검이며 실제 요구조사·사용자 평가·AI 성능·교육 효과 또는20,000건 앱 부하를 검증한 결과가 아니다.

같은 날 학교 API를 사용할 수 없는 상황에서 구글시트를 수정 가능한 합성 학생 데이터 원본으로 구성했다.28개 입력 필드를 계약으로 정의하고 active인 학생을 읽는 API와60초/수동 갱신·공통 화면 상태를 구현했다. 실제 시트에서 학점·GPA·상담 상태를 수정하여 열린 학생 상세와 집계가 갱신되는지 확인했고, 잘못된 학점 입력 시 정상 자료 유지와 오류 안내 및 원상복원까지 검증했다. 이후 학교 규모에 맞추라는 사용자 요청에 따라 현재 시트와 앱 표시 대상을 총1,000명으로 축소했다. 초기20,000건·256명 버전은 개발 이력으로 구분한다. 이 연결은 읽기 전용 단방향이며 향후 학교 API·인증된 비공개 자료를 같은 Student 계약으로 연결하도록 데이터 취득 부분을 분리했다.
