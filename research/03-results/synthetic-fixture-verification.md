# 합성 데이터 및 화면 연결 기술 검증

## 작업과 범위

2026-10-25, E-SYN-001 프로토콜에 따라 합성 학생 20,000건을 생성하고 256건을 교수자용 앱에 연결했다. 실제 학생 원자료·설문 응답·교수자 평정은 입력하지 않았다. 합성 자료는 기술적 검증용이며 실제 연구 참여자 수는 0명이다.

## 확인된 결과

- 고유 식별자·합성 표시·가짜 연락처 형식, 학점·GPA·점수 범위, 학점-이수율 계산 일치, 명시적 결측 표기를 검사했다.
- 같은 시드로 재생성한 20,000건 학생 JSON의 SHA-256이 일치했다. manifest의 생성 파일 해시도 확인했다.
- 데모 256건에서 학년4 × 모듈4 × 상황16의 조합 256개를 확인했다.
- 앱의 실행 시 무작위 학생 생성과 무작위 관계 링크를 제거하고 고정 fixture와 예시 관계를 사용했다.
- 대시보드의 학생 수·평균 이수율·진도율 30% 미만·상담 요청/대기 수를 같은 학생 집합에서 계산하게 했다. 근거 없는 전학기 증가·최근 상담 신청 시각은 제거했다.
- 전체 화면 및 모바일에 합성 데이터 배너를, 출력용 보고서에 합성 자료와 출력일 표시를 넣었다.
- TypeScript 검사와 Vite 프로덕션 빌드를 통과했다. 번들 크기 경고는 남아 있으며 최적화 후속 과제다.
- 로컬 프로덕션 브라우저에서 새로고침 전후 학생 표시 동일, 관리 화면256행·AI-SW 필터64행, 학생 상세·상담 화면·합성 관계256노드·모듈 통계 렌더링, 모바일 표시·가로 넘침 없음과 JS 예외 없음을 확인했다.
- 첫 네트워크 검사에서는 장식용 SVG 원까지 포함한 개수 비교가 실패했다. 학생 데이터가 결합된 노드만 세도록 검사 대상을 수정하여 통과했다. 이는 앱 결함이나 학생 데이터 누락으로 해석하지 않는다.

## 미검증 및 해석 제한

- 전체 20,000건은 파일 생성·데이터 제약만 확인했다. 앱에는 256건만 연결했다. 앱의 20,000건 부하·동시 접속 성능을 검증했다고 주장하지 않는다.
- 별도 음성 사례6건은 생성·보관했으나 앱 입력 검증·명령문 방어를 시험한 결과가 아니다.
- 확장 필드의 상담·성찰·선수요건·설계변경 정보는 저장 흐름 구현에 사용할 fixture다. 모든 필드가 UI·영속 저장·추천 알고리즘에 연결되었다는 뜻은 아니다.
- 기존 공통 상담 메시지, 모듈 추세·역량·취업 사례와 미연결 동선은 남아 있다. 글로벌 합성 배너로 성격을 알린다.
- 실제 학생과의 분포 일치, 요구도·만족도·공정성·AI 정확도·교육적 효과성·전문가 타당성은 검증하지 않았다. 생성한 사례의 경보 비율은 연구자 설계의 산물이며 학생 집단의 위험률이 아니다.
