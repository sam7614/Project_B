# 학술연구교수 B 연구 진행표

2026년도 인문사회학술연구교수 B유형 선정과제의 연구 일정과 제출물을 관리하는 개인용 체크리스트 앱입니다.

## 주요 기능

- 선정·협약부터 연구비 정산까지 시간대별 체크리스트
- 전체 진행률과 다음 핵심 일정 표시
- 완료 상태 브라우저 저장
- 전체·할 일·완료 필터
- 마감 30일·14일·7일·1일 전 브라우저 알림
- 핵심 일정 iCalendar 파일 내보내기
- 모바일 및 데스크톱 반응형 화면

## 사용 방법

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다. 체크한 완료 상태는 해당 브라우저의 로컬 저장소에 보관됩니다.

브라우저 알림은 앱이 열려 있을 때 작동합니다. Google Calendar 등 외부 캘린더에는 앱의 `캘린더 파일 받기` 버튼으로 내려받은 ICS 파일을 가져오면 됩니다.

## 기준 일정

- 연구기간: 2026년 6월 1일 ~ 2027년 5월 31일
- 학술활동 결과보고서 제출 예정: 2027년 4월 30일
- 연구비 사용실적보고 확인 예정: 2027년 8월 31일

실제 제출일은 한국연구재단 및 주관기관의 최신 안내를 우선합니다.

## 배포

정적 HTML 앱이므로 GitHub Pages에서 바로 게시할 수 있습니다.
