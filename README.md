# 학술연구교수 B 연구 진행표

2026년도 인문사회학술연구교수 B유형 선정과제의 연구 일정과 제출물을 관리하는 개인용 체크리스트 앱입니다.

## 주요 기능

- 선정 연구계획서에 근거한 월별 연구 과업 및 행정·제출 확인 체크리스트
- 연구과제 개요, 주요 산출물 및 이번 달 연구 계획
- 전체 진행률과 기한이 지난 미완료 과업 우선 표시
- 완료 상태 브라우저 저장
- 전체·할 일·완료 및 연구·행정·이번 달 필터
- 마감 30일·14일·7일·1일 전 브라우저 알림
- 핵심 일정 iCalendar 파일 내보내기
- 모바일 및 데스크톱 반응형 화면

## 사용 방법

별도 설치 없이 `index.html`을 브라우저에서 열면 됩니다. 체크한 완료 상태는 해당 브라우저의 로컬 저장소에 보관됩니다.

브라우저 알림은 앱이 열려 있을 때 작동합니다. Google Calendar 등 외부 캘린더에는 앱의 `캘린더 파일 받기` 버튼으로 내려받은 ICS 파일을 가져오면 됩니다.

## 기준 일정

- 연구기간: 2026년 6월 1일 ~ 2027년 5월 31일
- 연구계획서의 최종 보고서 제출 계획: 2027년 5월
- 학술활동 결과보고서: 요강의 연구 종료 1개월 전 제출 기준에 따라 2027년 4월 말까지 준비·제출 (과제별 정확한 접수 기한과 기관 내부 기한 확인)
- 2027년 8월 31일: 기존 일정표에서 이어온 사용실적보고 확인 잠정 목표일

월별 연구 과업은 선정 연구계획서를 따르며, 결과보고서의 요강 기준을 제외한 세부 날짜는 개인 실행 목표입니다. 과제별 공식 접수 공지와 기관 내부 기한을 확인하세요.

실제 제출일은 한국연구재단 및 주관기관의 최신 안내를 우선합니다.

## 연구 작업실

- 주소: https://project-b-lemon.vercel.app/research.html
- 기존 일정표에서 **연구 작업실** 버튼으로 이동합니다.
- `research.html`, `research.css`, `research-schema.js`, `research.js`로 구성한 정적 앱입니다. 별도 빌드와 외부 JS 라이브러리 없이 동작합니다.
- 선정 계획서의 목적·방법·범위·산출물·일정을 분석해 17개 보고서 항목과 조사/분석/설계/검토/AI 활용 기록 틀을 제공합니다. 목적·범위 두 항목의 초기 문장은 계획서 기반 초안이며 연구 결과가 아닙니다.
- 이 작성 틀은 재단의 공식 지정 서식이 아닙니다. 최종 제출 공지의 서식과 항목·분량을 확인해 옮겨야 합니다.

### 사용 흐름

1. **문헌·웹 자료함**에서 제목, 저자, 서지, URL/DOI, 열람일, 태그, 요약, 인용 위치와 확인 상태를 저장합니다.
2. **연구 기록**에서 실제 수행과 의사결정, 연결 출처·보고서 항목 및 산출물 파일을 남깁니다.
3. **최종보고서 작성**에서 연결된 근거를 확인하며 본문을 작성합니다. 입력 후 0.5초 또는 항목 이동 시 자동 저장됩니다. 검토 완료 본문을 다시 편집하면 작성 중으로 전환됩니다.
4. 중요한 시점에 **이 버전 보관**을 눌러 항목별 최근 10개 버전을 보관합니다.
5. **전체 미리보기**, **보고서 내려받기(Markdown)**, **인쇄 / PDF**로 본문을 출력합니다. 참고문헌은 검증한 서지에 맞게 직접 정리하며, 연결 출처 목록은 검토 보조용입니다.

### 저장·백업

- 입력 내용·첨부파일은 해당 도메인의 현재 브라우저 **IndexedDB**에 저장됩니다. 서버, GitHub, 다른 기기로 자동 전송·동기화되지 않습니다. HTTP(S) 환경에서 사용하세요.
- 브라우저 데이터 삭제, 기기 교체 또는 시크릿 창 종료로 자료가 사라질 수 있으므로 **전체 백업 받기**로 정기 보관하세요.
- 전체 JSON 백업에는 프로젝트, 출처, 연구 기록, 보고서 본문·버전, 첨부파일 및 일정표 완료 체크 상태가 포함됩니다. 복원은 확인 후 현재 내용을 교체합니다.
- 첨부파일은 파일당 10 MB까지 허용합니다. 브라우저 저장 공간 한도는 환경에 따라 다르며, 저장 실패 시 입력 내용을 유지하고 경고합니다. 이때 백업 후 저장 공간을 확인하세요.
- 오래된 탭에서 다른 탭의 변경을 덮어쓰려는 경우 저장을 중단합니다. 해당 탭의 백업을 받은 후 다시 열어 주세요.
- 실명·연락처·원본 동의서 등의 식별자료는 승인된 별도 보관소에서 관리하고, 작업실에는 익명화된 기록과 보관 위치만 남깁니다.
- 백업에 포함된 파일은 사용자가 첨부한 원본입니다. 신뢰할 수 있는 백업을 사용하세요.

### 참고한 설계 방식

- [Zotero의 컬렉션·태그](https://www.zotero.org/support/collections_and_tags): 하나의 자료를 여러 보고서 항목에 연결하고 태그·검색으로 찾는 방식.
- [Notion Web Clipper](https://www.notion.com/help/web-clipper): 원본 URL을 유지하며 자료를 축적하는 방식. 이 앱은 웹 자동 수집 기능 대신 URL·발췌·연구 메모의 수동 저장을 제공합니다.

### 검증

격리된 Edge 브라우저에서 자료·연구 기록 생성/편집/삭제, 출처 연결, 첨부 다운로드, 자동 저장과 새로고침, 작성 버전 복원, Markdown 출력, 첨부 포함 백업·복원, 잘못된 백업 거부, 입력 문자열의 HTML 이스케이프, 모바일 화면, 일정표 호환성을 확인했습니다. 여러 탭의 동시 변경 충돌과 인쇄 화면도 별도로 점검합니다.
